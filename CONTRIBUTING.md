# Contributing to Logos

Thank you for your interest in Logos.

## Ways to contribute

You can help by:

- Reporting bugs
- Improving documentation
- Testing Windows or macOS releases
- Suggesting language-learning features
- Improving accessibility
- Adding or improving tests
- Proposing dictionary / learner-expression improvements
- Helping verify third-party licensing and attribution

## Bug reports

Please include:

- Operating system and version
- Obsidian version
- Logos version
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Exact error message
- Screenshot if useful

Do not upload private notes, personal documents, passwords, tokens, or other sensitive data.

## Feature requests

Please explain:

- The problem you want to solve
- Who the feature would help
- Your proposed workflow
- Whether it affects Reader, Dictionary, Vocabulary, PDF, pronunciation, or another area

## Pull requests

Before submitting a pull request:

1. Keep the change focused
2. Explain what changed and why
3. Test the change in Obsidian
4. Avoid committing generated installers, large model files, or `node_modules`
5. Preserve third-party attribution where applicable
6. Update documentation when user-facing behavior changes

## Coding and project style

- Prefer readable, maintainable code
- Avoid unnecessary external services for core functionality
- Preserve the local-first design goal
- Keep beginner users in mind
- Use clear error messages instead of raw implementation details when possible

## AI-assisted contributions

AI-assisted code is welcome, but contributors remain responsible for reviewing, testing, licensing, and understanding what they submit.
